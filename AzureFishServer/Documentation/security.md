# 首期服务端安全边界

## 已实现

- 默认仅回环 HTTP＋虚构测试数据，运行要求显式测试开关。没有真实账号、Apple、局域网或发布模式；客户端 TLS／ATS 配置不变。
- 密码通过 Vapor 的异步 bcrypt（默认 cost 12）处理，不占用事件循环；测试 cost 4。不存在账号仍校验等成本的随机 dummy hash。登录／注册按规范化账号以及来源地址限流，等待数据库锁的请求有上限。
- 外部随机 256 位主密钥通过文件注入；HKDF-SHA256 以环境与用途派生独立 AES-GCM 与 HMAC 密钥。账号查找、令牌和请求指纹使用带用途的 HMAC-SHA256，数据库不存原密码或明文令牌。
- 用户 payload（账号名、密码摘要、昵称、简介及资料时间戳）和幂等响应通过 AES-256-GCM 加密。每次写入使用库生成的随机 nonce；AAD 采用长度分隔编码，绑定格式、环境、用途和记录 UUID。交换记录、篡改、错钥均无法得到可消费明文。
- 原库启动先验证加密标记。缺钥／错钥／环境不匹配时拒绝打开业务，不自动创建新钥、删库或降级为明文。
- 数据目录权限 0700、密钥文件 0600。文件锁保证单进程；数据库事务把资料、会话与幂等结果一起提交。刷新重放撤销先提交后报错，避免异常回滚撤销。
- 错误响应不包含底层异常。请求体、账号、资料、密码、令牌和数据库绑定参数不写业务日志；诊断仅含服务端 request_id 与稳定错误分类。响应禁止 HTTP 缓存。

## 不提供的保证与上线门槛

Fluent SQLite **不是 SQLCipher 整库加密**：表名、记录 ID、会话设备 ID、索引摘要、版本、过期时间和文件大小仍是元数据。服务端字段加密不等于客户端 SQLCipher，也不等于消息端到端加密。加密无法防护持有运行进程或密钥权限的攻击者。

当前是本地开发骨架，未提供生产 HTTPS、密钥轮换、密钥托管、加密备份／灾难恢复、全量持久化限流、定时物理清理、账号删除、真实 Apple 或多节点一致性。密钥文件与数据库不得作为生产部署方案直接沿用。

开放真实账号前必须完成 HTTPS 与证书部署、密钥管理／恢复演练、密码和限流策略评估、数据保留／删除任务及安全审查。客户端另需通过 GRDB／SQLCipher、Keychain 与账号缓存验收。当前没有因服务端可登录而解除这些门槛。

参考实现依据：[Vapor 密码 API](https://docs.vapor.codes/security/passwords/)、[Fluent 事务](https://docs.vapor.codes/fluent/transaction/)、[Apple Swift Crypto](https://github.com/apple/swift-crypto)、[Apple SwiftProtobuf](https://github.com/apple/swift-protobuf)。
