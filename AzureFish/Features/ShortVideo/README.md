# ShortVideo

参照 `Features/Chat` 的职责划分和 UIKit／QuickLayoutKit／ListKit 组合组织。业务状态不依赖视图重建，播放器不放入可复用 Cell。独立“短视频”Tab 的容器保持页面实例，切走时停止播放，返回时恢复当前素材；发现页同时提供快捷入口。

| 目录 | 职责 |
| --- | --- |
| `Controllers` | 页面组合、事件绑定与导航；`+Playback` 管理唯一播放器，`+Interaction` 路由评论、分享和来源页 |
| `Models` | 播放资格和异步加载身份，阻止旧页完成回调串播 |
| `ViewModels` | 视频分页、点赞、评论分页与草稿、稳定写请求身份；只接收服务端确认的互动状态 |
| `Views` | QuickLayoutView 页面组件和 ListKit 映射；媒体 Cell 提供原比例画布，评论 Cell 管理头像、昵称、正文和操作菜单 |
| `Support` | 账号作用域请求、加密媒体导入、受保护租约和停止屏障 |

架构与布局技术参考 Chat，产品交互参考抖音：画布覆盖页面，视频保持素材比例并居中留边，顶部仅保留热门标题、静音和信息菜单，尾缘纵向排列点赞、评论、分享，作者、标签与紧凑的 Pixabay 来源链接置于底部；暂停图标在画面中央出现，进度条贴近底部。透明浮层的空白区域将点击和上下滑动交还列表，支持双击点赞；只在按钮区域拦截触摸。计数范围与分享语义在信息菜单说明，并保留在无障碍提示中。视频页隐藏原生导航栏，发现入口保留浮层返回按钮；独立 Tab 继续使用系统标签栏，只调整该标签选中时的颜色。浮层独立处理水平与底部安全区；regular 宽度的顶部控制区扣除已有安全区后保留首行空间，避让系统窗口按钮，视频画布不跟随缩小。评论列表通过内容 inset 避让输入区，复用 Chat 的 `BottomObstructionCoordinator` 与 QuickLayout 键盘上下文，保留阅读位置。输入区根据窗口宽度、文字大小和正文增长，维持同一个 UITextView；评论 Cell 使用 QuickLayout 自适应高度并通过菜单删除自己的评论。输入框提供本地化占位提示，空内容不可发送；发送采用带完整无障碍标签的箭头按钮，避免大字体压缩输入宽度。视频浮层文字支持动态字体并限制最大字号，以保留视频与交互空间，评论正文不采用该限制。

独立 UIKit 组件在同文件提供 `#Preview`。视频 layer 的 frame 仅在 Cell 内按本地 bounds 更新；这部分精确几何不交给文本布局系统。iOS 15 的最低版本保持不变。

协议、配置、存储生命周期和本次验证见 [功能说明](../../../Documentation/ShortVideo/README.md)。

翻页拖动开始时暂停并保留当前就绪帧；停在同页时复用播放器，切到新页时先按旧视频身份保存位置并释放租约，再加载新页。不预取相邻资源，不改变账号加密下载与临时明文生命周期。
