| SEC-07 | 普通退出、清本地、账号删除分别执行 | 退出保留加密历史与钥；清理只影响目标账号 | Keychain／文件／数据库集成 |
| SEC-08 | 备份恢复但缺旧钥、误选环境、损坏密文 | 停止恢复，不静默丢数据；无跨环境打开 | 恢复演练 |
| SEC-09 | 服务端同名不同大小写注册、HMAC 换钥中断 | 唯一用户；全库同一有效查询代次 | 服务事务与维护故障注入 |
| SEC-10 | 服务端复制字段到另一行或替换头像文件 | AAD／tag 拒绝，不读出其他用户数据 | API＋存储集成 |
| SEC-11 | 恢复含已删除账号的旧备份 | 删除日志重放后仍不能登录；日志缺失则维护模式 | 备份／删除恢复演练 |
| SEC-12 | 旧幂等回执跨密钥轮换重试 | 按原 key_id 验证，不能执行两次业务 | 会话与幂等集成 |
| SEC-13 | 错误 CA、过期证书、主机名不符、真实数据 HTTP | 拒绝请求，不跳过 TLS；Debug 虚构回环仅独立环境可用 | URLSession 与真机联调 |
| SEC-14 | 密钥提供器不可用、服务重启 | 不自动生成新钥；/health 不 ready | Mac Keychain 真实集成 |

SQLCipher 兼容门槛包括 iOS 15、FTS5、迁移、连接池、WAL、设备／模拟器链接及一致性备份。未来 IM 大文件流式格式未冻结前不得把头像加密测试标为视频／文件已支持。
