# 聊天详情、设备设置与应用内提醒

> 状态：2026-09-28 已接入客户端，验证结果见本文末尾。此功能不包含 APNs、锁屏或后台消息提醒。

## 页面与权限

真实会话的 iOS 26+ 原版页面及 iOS 15～25 兼容页面共用右上角「聊天详情」导航。通过当前导航栈 push，连续点击不重复入栈；返回保留原聊天控制器和草稿。

详情采用语义灰色背景、白色分组和成员网格。单聊显示对方；群聊仅显示有效成员，默认两行，更多成员进入完整网格。成员列数依据当前内容容器和字号计算，宽容器限制为 640 点。系统导航和控件遵循当前系统外观。

群主可改名、加入成员、移除成员、转让及解散；普通有效成员可退出。关闭的会话不显示群变更动作。网络动作沿用服务端既有版本检查、幂等身份和确认流程，失败刷新权威状态。未实现的群公告、背景、举报入口不展示。

## 本设备偏好

`ConversationLocalPreferences` 存储在现有账号 SQLCipher 库的 `meta` 中，以 `preferences:<conversationID>` 为键，字段为 `isPinned`、`isMuted`，默认关闭。该结构是客户端本地类型，不是网络契约。

置顶组优先，同组继续按最新消息时间倒序、ID 升序排列。免打扰仅抑制应用打开时的消息横幅，不减少未读、不自动标记已读，也不影响其他设备。

写入成功后发布更新；失败保留原设置并提示。普通退出、重新登录以及清空聊天记录保留偏好；账号数据清除时随账号库删除。设置不使用 UserDefaults、不新增服务端接口。

## 会话列表与置顶样式

2026-09-28 补充：草稿摘要、置顶折叠及精确排序规则见 [会话排序与显示](conversation-ordering.md)。

会话在收到非系统聊天内容、本机受理发送进入持久队列，或保存内容变化的非空草稿后显示；仅打开页面、加载或重复保存草稿、系统提示不触发。曾有内容的会话清空后仍保留，摘要尊重清空边界，最近活动时间不重置。失败的待发送消息也保留显示资格。

置顶会话优先排列，同组按最近聊天内容／受理发送时间倒序、ID 升序。置顶行使用系统 `secondarySystemBackground`，普通行使用 `systemBackground`，保留原生按压和选中反馈；会话列表不显示分割线或置顶图钉，无障碍描述保留“已置顶”。免打扰图标和未读徽标独立展示。无障碍大字号将头像放入原生 leading accessory，避免 RTL 混合文本环绕重叠；字号及语言变化显式重配行，不重建会话或改变列表业务状态。

列表尾侧原生滑动操作为“标记未读”“不显示”“删除”，RTL 遵循系统方向，不允许整段滑动自动执行。“标记未读”仅保存本设备提醒，无真实未读时显示红点，有真实未读时仍显示数量。聊天页面实际进入后清除手动提醒，不倒退服务端已读水位。

“不显示”仅移出列表并保留记录；“删除”确认后在同一事务清空本机历史并移出列表，仍保留草稿、待发送内容、置顶／免打扰设置及好友／群成员关系。两者清除手动提醒，不修改真实未读。隐藏优先于置顶；收到隐藏边界之后的新聊天内容、主动受理新发送或修改非空草稿时恢复。隐藏前的待发送消息后续发送成功也可恢复。旧历史补拉、重复数据、回执、撤回和系统提示不解除隐藏。

`chat-v5-conversation-list` 在账号 SQLCipher 库新增 `conversation_list`，记录显示资格、隐藏截至序号、手动未读、最近活动时间及已检查的历史边界。旧版本没有实际展示日志，迁移依据已有聊天内容、清空痕迹和发送队列回填，不将所有旧空会话视为曾显示。首次快照摘要不足时同步器分页核实历史；仅系统消息的已检查范围不会每次重查；查询失败保留未检查状态待下次重试，不阻断正常收发队列。普通历史分页可以证明会话曾有内容，但不解除用户隐藏。

列表、列表搜索和空状态使用同一可见集合，同账号多个窗口传播状态；写入失败不先行移除行。普通退出保留本机状态，清除账号数据时随库删除，不增加服务端接口或协议字段。

## 本地搜索与清空

搜索范围是当前会话已同步到本机的文字及链接文字。采用数据库设计中的 NFKC／大小写折叠、Han 单字与双字 token、英文与阿拉伯文整词规则；查询多段取 AND，Han 连续文字再做子串复核。FTS 仅接收程序生成的 ASCII token，不执行用户提供的 MATCH 表达式。界面语言变化不改变正文或索引。

`chat-v4-local-details-search` 迁移重建已有 `message_search`，仅在加密库中回填。当前规模采用同事务维护投影，尚未实现数据库远期设计的 `search_dirty` 后台百万消息索引架构，不将其标为完成。

结果按服务端时间和 ID 倒序，以游标每页返回 50 条；复核隐藏、撤回和账号成员区间，点击时再次校验。结果展示发送者、当地日期时间与命中摘要；定位读取目标附近至多 101 条消息，保留草稿，可返回最新消息。

清空记录保存 `conversation_clear` 的截至序号，并隐藏当前记录、删除搜索投影；后续补拉的更早消息仍隐藏。清空不会删除对方记录、草稿、待发送内容或设置，不改变群成员身份及已读水位。

## 应用内横幅

`ChatStore.apply(events:expected:)` 在同一事务保存事件及游标后返回新入库的他人消息。已存在消息、本人消息、系统消息和撤回状态不产生新消息候选；历史分页和快照不走提醒通道。

`ChatEngine` 提供独立临时消息流，并按前台周期建立同步基线。首次同步、每次返回前台主动触发的首次补拉不弹横幅；旧前台周期的迟到同步不能在新周期发出提醒。横幅是临时提示，不承担权威消息送达。

账号根容器在显示前复核消息、账号和本设备免打扰；当前浏览的会话（包括详情和搜索子页面）不提醒。摘要显示发送者、文字片段或媒体类型。同批消息按会话合并，当前仅保留一个横幅，5 秒后自动收起，也可关闭或点击进入会话。同账号任一场景提交的前台消息事件交给最近触摸的活动场景展示一次，不转移输入焦点。后台、退出、切账号、消息失效或开启免打扰会移除相关横幅。

所有网络同步仍使用现有 HTTP／WebSocket 契约。没有申请系统通知权限、注册 APNs token 或修改服务端推送逻辑。
