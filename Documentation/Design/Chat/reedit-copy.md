# 撤回与重新编辑四语言文案

与 App String Catalog 的 `chat.live.*` 键保持一致。群成员姓名使用 `%@` 参数，不拼接本地化句子；名称作为用户内容原样显示。

| Key | 简中 | 繁中 | English | العربية |
| --- | --- | --- | --- | --- |
| `chat.live.revokedSelf` | 你撤回了一条消息 | 你撤回了一則訊息 | You recalled a message | لقد سحبت رسالة |
| `chat.live.revokedOther` | 对方撤回了一条消息 | 對方撤回了一則訊息 | The other person recalled a message | سحب الطرف الآخر رسالة |
| `chat.live.revokedMember` | %@撤回了一条消息 | %@撤回了一則訊息 | %@ recalled a message | سحب %@ رسالة |
| `chat.live.reedit` | 重新编辑 | 重新編輯 | Edit again | إعادة التحرير |
| `chat.live.replaceDraftTitle` | 替换当前草稿？ | 取代目前的草稿？ | Replace the current draft? | هل تريد استبدال المسودة الحالية؟ |
| `chat.live.replaceDraftBody` | 当前文字将替换为撤回的内容，已选附件会保留。 | 目前文字將替換為收回的內容，已選附件會保留。 | Your current text will be replaced with the recalled message. Selected attachments will be kept. | سيُستبدل النص الحالي بالرسالة المسحوبة، مع الاحتفاظ بالمرفقات المحددة. |
| `chat.live.replaceDraft` | 替换 | 取代 | Replace | استبدال |
| `chat.live.reeditExpired` | 已超过重新编辑时限 | 已超過重新編輯時限 | The editing window has expired | انتهت مهلة إعادة التحرير |
| `chat.live.reeditUnavailable` | 原文暂时不可用，无法重新编辑 | 原文暫時無法使用，無法重新編輯 | The original text is unavailable for editing | النص الأصلي غير متاح لإعادة التحرير |
| `chat.live.revokeNoRecovery` | 消息已撤回，但无法重新编辑 | 訊息已收回，但無法重新編輯 | Message recalled, but editing is unavailable | سُحبت الرسالة، لكن إعادة التحرير غير متاحة |
| `chat.live.revokeFailed` | 未能撤回消息，原消息已保留 | 未能收回訊息，原訊息已保留 | Couldn’t recall the message. The original message is kept. | تعذّر سحب الرسالة. تم الاحتفاظ بالرسالة الأصلية. |
| `chat.live.revokeConfirming` | 正在确认撤回结果，请稍后查看 | 正在確認收回結果，請稍後查看 | Confirming the recall result. Please check again shortly. | جارٍ التحقق من نتيجة سحب الرسالة. يُرجى التحقق بعد قليل. |
