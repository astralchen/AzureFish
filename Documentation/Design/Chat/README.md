## 权威来源与边界

消息与权限以[服务端 IM 契约](../../../AzureFishServer/Documentation/im-contract.md)和[媒体契约](../../../AzureFishServer/Documentation/media-contract.md)为唯一网络来源。本设计不增加协议字段；页面通过业务状态呈现结果，不直接绑定 Protobuf、游标或资源授权。

主标签为“聊天／通讯录／我”。首次完成登录进入聊天列表，之后恢复当前账号上次标签、选中会话及阅读位置。账号切换先结束旧会话的页面任务与媒体访问；其他账号的草稿和消息不能闪现。普通离线保留会话，明确认证失败才进入已有登录恢复流程。

原有演示聊天保留独立命名空间，也是本次视觉依据；真实接入代码与验证结果见 [实施记录](contacts-implementation.md)。iOS 15 起完整聊天是新目标，旧系统运行验收尚未完成。通用 WebSocket 内存队列不能替代持久消息 outbox。

好友申请需要双方确认；新私聊发送、建群与加人使用已确认好友。删除好友双向解除关系但保留历史。不提供在线状态、输入中、引用回复、编辑、reaction、跨会话转发、群公告、免打扰和推送通知设置。头像使用默认身份图形，不新增头像上传。

## 设计规则

- UIKit／QuickLayoutKit／ListKit 保持既有工程方向。Figma 可编辑组件表达业务与布局意图，真实控件由系统实现。
- regular 且可用宽度 ≥840 pt 使用双栏，列表默认 320 pt、范围 280～360 pt；其余情况单栏推入。详情设置在内容栏继续导航。
- 消息内容区在宽屏居中，最大宽度 720 pt；气泡最大宽度沿用工程 `min(420, max(140, width × 0.75))`，短消息按内容收缩，长文本可换行。
- Figma 手机 390×852、窄屏 320 pt 和 iPad 窗口只是测试尺寸，不用于实现中的机型判断。
- 阅读、选择、草稿、附件顺序与播放状态归业务状态所有，不能因主题、语言、窗口或 cell 复用而重建。
- 四语言与 RTL 使用系统字体、语义方向和本地化格式；Noto 是沿用现有文件的设计字体替代，不要求 App 内置它。
