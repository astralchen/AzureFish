# 聊天交互规格

> 交互目标；当前实施与验收状态见 [实施记录](contacts-implementation.md)。服务端接口、权限和限额优先于界面样例。

## 1. 导航与会话列表

首次登录进入“聊天”；后续启动恢复当前账号的标签与会话。紧凑布局列表推入会话，返回恢复原列表位置；宽布局左侧列表、右侧会话，未选择时提示“选择一个聊天”。折叠优先展示正在阅读的会话，展开恢复选中项。资料／群设置在详情栏继续导航。

列表行包括默认头像、名称、最近消息摘要、时间、未读数；群摘要带发送者。时间和数量按当前 locale 格式化。草稿优先于普通摘要；失败状态使用图标与文字，不仅依赖红色。不存在已加载消息时显示“暂无消息”，不能用未同步解释为空会话。

列表按最后已接受消息时间排序；草稿或等待中的发送不改写服务器时间。发送失败在原会话标示；后台同步不使正在操作的行突然跳走，交互结束后再更新排序。未读显示服务端权威值，徽标显示最多“99+”，VoiceOver 读出完整数量。

会话行与 Tab 徽标统一红底白字。聊天 Tab 显示所有会话未读总数，0 时隐藏，超过 99 显示“99+”；搜索筛选不改变总数，切换 Tab 不清空未读。通讯录 Tab 独立显示待处理的收到申请数量。

| 状态 | 呈现和恢复 |
| --- | --- |
| 首次同步 | 列表占位和同步提示；没有缓存时不展示空列表插画 |
| 无会话 | 引导“发起聊天／创建群聊”，没有伪造的示例联系人 |
| 离线有缓存 | 保留列表，非模态提示离线；允许打开已缓存记录及准备草稿 |
| 加载失败 | 保留缓存与滚动位置；“重试”只重新加载，不创建会话 |
| 新建会话需要网络 | 查询／创建未成功前不分配临时权威会话，不允许离线向未知目标发送 |

“发起聊天”从可搜索的已确认好友中选择，重复进入打开已有私聊。“通讯录 → 添加好友”使用精确账号查询，确认资料后发送申请。自聊、未找到、限流和断网分别解释并保留输入；旧请求不得覆盖新输入。导航栏“＋”提供发起聊天和创建群聊，不在列表底部放置两个大按钮。

通讯录包含“新的朋友”和按当前语言排序的已确认好友。Tab 徽标为待处理收到申请数量；申请支持接受、拒绝和取消。删除好友双向解除关系、历史保留。非好友私聊输入区显示添加好友提示，草稿保留并可复制或删除。

## 2. 时间线、输入与消息身份

撤回占位和本人文本三分钟重新编辑遵循 [专项说明](revoke-reedit.md)。重新编辑只恢复本机草稿，发送后是新的消息，原撤回占位保持不变。
时间线按服务器接受顺序排列，未确认的本机发送暂置于底部；收到自己的权威消息时合并为同一气泡，不插入副本。虚构的“输入中”和固定联系人不进入真实页面。

首次打开先恢复阅读锚点；没有锚点时定位第一条未读，均已读时到最新。顶部按需补历史，保持原可见消息与像素偏移；正在阅读历史时新消息只增加“新消息／回到最新”按钮。未读分隔线在本次阅读会话内保持稳定。历史边界变化时重新拉取，不瞬间清空已显示的授权内容。

文字输入支持换行与纯文本粘贴。格式化文本去掉样式，链接作为文字发送。空白消息不发送；字符数／UTF-8 字节达到服务端限制时就地提示并保留内容。系统键盘听写可用时作为系统输入能力，不承诺服务端语音转写。

点击发送后，先将内容和稳定身份写入持久 outbox，再移出编辑器；落盘失败保留编辑器内容。页面重建、语言变化或窗口变化不能再次提交。会话草稿与 outbox 按环境和账号隔离，不能迁入演示 `demo.chat` 的无账号文件。

| 可见发送状态 | 含义 | 操作 |
| --- | --- | --- |
| 等待网络 | 尚未提交；内容已安全保留 | 自动恢复；可取消并恢复草稿 |
| 发送中 | 正在提交原操作 | 禁止重复发送；可离开页面 |
| 正在确认发送结果 | 可能已接受，但响应丢失 | 先同步／对账；不能立即宣称取消成功 |
| 已发送 | 服务端已接受并分配权威身份 | 可查看回执、在时限内撤回 |
| 已送达 | 接收者水位确认送达 | 不把服务器 ACK 当送达 |
| 已读 | 接收者阅读水位确认 | 不显示模拟计时回执 |
| 发送失败 | 明确拒绝或永久失败 | 解释原因，允许修正／重试／本机移除 |

暂时断网自动重试原身份；过期操作先对账，身份冲突停止盲目重发。真正修改失败内容时作为新草稿发送，旧身份停止重试。已接受消息不能“取消发送”；只能按规则撤回。

## 3. 读取、群回执与同步

WebSocket 只通知“需要同步”。恢复连接、提示变化或接收缺口均触发 HTTP 补拉；只有本地事务提交后才能更新 checkpoint。页面连接提示不展示内部游标或错误分类。

送达确认要求当前设备已完整覆盖相应授权区间。已读仅在 App 前台、会话实际可见且消息进入已阅读范围时推进；不因打开页面、预加载、收到提示或乱序最大序号而跳过缺口。媒体消息的阅读以消息信封可见为准，不要求先下载完整视频。窗口未激活或详情遮挡时不借后台布局标记阅读。

私聊只在最新连续自发消息末尾显示状态；其他消息长按可查看详情。群聊显示“已读人数／发送时接收人数”，可点击查看明细，只有发送者有权限。摘要与明细使用同一版本；加载新明细时保留旧版本并注明更新中，不能拼成虚假人数。退群不改写旧消息分母。

## 4. 消息菜单、删除与撤回

菜单锁定消息稳定身份，不依赖 cell 索引。普通文本复制；文件／媒体提供下载后保存、系统分享；失败消息提供重试；本人且未过期的已接受消息提供撤回。未知内容显示占位，可同步信封和基本操作，不渲染未经识别的 payload。

| 操作 | 完成条件 | 取消／失败 | 完成后焦点 |
| --- | --- | --- | --- |
| 复制文字 | 系统剪贴板写入完成 | 不修改原消息 | 原消息 |
| 重试 | 原操作被接受或对账成功 | 保留气泡和原身份 | 同一气泡的状态 |
| 撤回 | 服务端返回当前撤回终态 | 超过 120 秒／权限失败保留消息并解释 | 撤回占位 |
| 本机删除 | 当前账号本地删除标记提交 | 确认前取消无变化 | 相邻消息；无消息时输入区 |
| 清空本机记录 | 本地隐藏边界及索引清理提交 | 草稿／未确认发送保留；不替代撤回 | 会话空状态 |

本机删除和清空不向其他设备传播，不改变已读，也不退出群；后续历史同步尊重本机标记，防止旧消息复活。新消息仍可出现。确认文案明确影响范围。

撤回成功后移除正文及当前消息的媒体预览，停止此消息的播放／下载，分享和保存入口失效。正在浏览时显示不可用状态并返回原阅读位置。其他消息仍引用同一资源时不误删其访问。保存到照片／文件／外部应用的副本不能远程收回。

## 5. 媒体草稿、上传与发送

附件选择使用系统相册／文件接口，权限拒绝仅阻止对应操作；始终保留取消及其他输入方式。无完整原件、导入中或损坏的项目不能提交。Live Photo 的照片和配对视频作为一项，缺件或错配不能退化成成功 Live Photo。

媒体组允许照片、动图、视频、Live Photo 混排，最多 20 项；顺序与预览编号一致。提供拖动排序及 VoiceOver“上移／下移／移除”。普通文件与语音各成一条。删除最后一个附件后恢复纯文字草稿。

文字和附件共存时展示明确分段及顺序；连续媒体合并为组，文字、文件、语音单独成条。点击“发送 N 条消息”逐项提交，不承诺跨消息原子性。前一项失败或结果未知时暂停后续项；显示哪些已发送，重试仅处理剩余内容。

| 类型 | 当前开发限额 | 界面检查 |
| --- | --- | --- |
| 图片／动图 | 单原件 ≤25 MiB、≤100 MP | 保留原件；超限就地提示 |
| 视频 | 单原件 ≤512 MiB | 不承诺自动压缩或统一转码 |
| Live Photo | 照片 ≤25 MiB、配对视频 ≤512 MiB | 验证完整配对 |
| 媒体组 | ≤20 项、原件合计 ≤1 GiB | 全组就绪后发送 |
| 语音 | 1～120 秒、≤20 MiB | 不足 1 秒提示；120 秒自动停止进入试听 |
| 文件 | 单原件 ≤512 MiB | 文件名安全显示，不执行、不解压 |

限额和处理能力以 `/media/capabilities` 为准；未取得能力时不猜测可提交，保留选择并允许重试。开发上限说明不混入日常聊天页面。

上传在用户确认发送后开始；后台排队状态属于已持久化的发送任务。未点击发送的附件保持草稿。每个条目显示准备／上传／处理／就绪，整体进度按原件字节加权；上传 100% 后改为“正在处理”，不虚构处理百分比或剩余时间。

暂时断网暂停并显示等待网络，前台恢复后续传缺失块。普通离线不退出账号；同账号重新登录先核对任务身份与状态。服务端已过期或处理永久失败时保留本地原件，用户重试才建立新附件身份。磁盘／配额不足保留草稿并提供重试或移除，不自动删除已发送内容。

取消仅停止尚未提交的内容并保留草稿。取消竞态遇到已接受结果时展示已发送状态，允许撤回；未知结果先确认，不能用“已取消”掩盖已接受消息。退出账号停止任务；再次登录不因恢复页面擅自发送用户已取消的内容。

## 6. 媒体浏览、下载与系统接管

照片支持缩放和分页，媒体组显示当前位置；动图、视频和 Live Photo 提供播放／暂停及静态封面。默认不自动播放有声音内容；降低动态效果时避免自动动画，提供手动播放。Live Photo 除长按外提供可访问的播放动作。单次只播放一个音视频源，切换／离页按业务状态协调。

预览与原件分开：缩略图可先展示，原件按需下载，显示大小和进度。下载完成必须校验长度与摘要，失败时原件不可保存／分享。授权过期自动续期，不把五分钟授权当作文件有效期。离线优先展示已验证缓存，缺失内容显示重试，不用永久空白。

文件只显示名称、类型、大小和下载状态；下载后交给系统文件保存／允许的系统预览，不建立 Office 等复杂自定义预览。系统分享与保存属于明确用户动作，确认后才交出完整可用数据。

| 操作 | 入口／结果 | 取消和恢复 | 焦点 |
| --- | --- | --- | --- |
| 下载原件 | 预览页／文件卡片 → 校验后可用 | 取消下载保留已验证分块，不撤回消息 | 原下载控件 |
| 保存到照片 | 完整原件 → 系统权限／写入结果 | 权限拒绝说明并可打开设置；仍可浏览 | 保存按钮／完成提示 |
| 保存到文件 | 完整原件 → 系统位置选择器 | 取消保持聊天文件 | 文件卡片 |
| 分享 | 完整原件 → 系统分享面板 | 取消不改消息；失败可重试 | 分享按钮 |
| 内容被撤回 | 浏览中响应权限变化 | 停止访问，显示不可用；不自动反复授权 | 关闭按钮，返回原消息 |

## 7. 群管理与历史权限

创建群聊必填群名（最多 64 Character），选择至少一位其他账号，不允许重复或自选；创建成功再进入权威会话。当前开发群容量为最多 100 个历史不同成员，不是最多 100 个当前在线成员。达到上限明确提示，不能依赖“移除一人”保证释放名额。

群主可改名、直接添加已存在账号、移除普通成员、转让给当前成员和解散。普通成员仅可退出。群主退出入口解释须先转让或解散；不能移除自己绕过转让。添加选择不等于创建联系人关系。

| 操作 | 确认与成功结果 | 失败恢复／焦点 |
| --- | --- | --- |
| 改名 | 保存成功显示新群名 | 版本冲突保留编辑并展示最新资料；焦点回字段 |
| 添加成员 | 显示准确账号、确认后等待服务器 | 已在群／容量限制刷新名单；焦点回被操作成员 |
| 移除成员 | 点名确认影响新消息权限 | 权限变化／目标已离开刷新名单，不误操作下一行 |
| 转让群主 | 明确目标和自己降为普通成员 | 等待成功再更新操作菜单；焦点回详情标题 |
| 退出 | 说明保留授权历史与草稿 | 失败仍在群，不提前关闭合法发送入口 |
| 解散 | 说明所有成员停止发送、无法撤销 | 成功展示只读历史；失败保留当前群 |

被移除、退出和解散都关闭发送入口，展示具体原因；保留草稿可复制或删除。旧授权历史可读，入群前和离开期间的消息不可补拉。重入显示缺口说明，不生成伪造的“某人入群”权威系统消息；离开后的群资料使用服务端冻结视图。

## 8. 适配、文案与可访问性

四语言遵循现有 AppLocalization 与 String Catalog，不新增语言管理器。阿拉伯语镜像导航、行布局和气泡语义方向；昵称、账号、URL、时间技术串正确处理双向文本，媒体不镜像。错误使用稳定错误码映射完整本地化句子，不直接显示原始服务器文本。

触控区域至少 44×44 pt。VoiceOver 将消息按发送者、内容、时间、状态朗读；上传进度合并节流播报，不逐分块打断。新消息不抢焦点，菜单关闭回原消息，删除后移到相邻项目。输入区、媒体和群成员操作均提供可访问标签。

Dynamic Type 使用内容高度与换行；大字体时缩短每行操作数量而非压缩文字。旧系统保持原生非玻璃；高对比与降低透明度使用实色底和可辨边界；减弱动画不破坏完成状态。iPad 分屏、硬件键盘和局部遮挡只调整当前有效内容区。

原型中的阶段切换均为预设结果，不能证明网络时序、权限、系统组件、VoiceOver、键盘或焦点已经实现。运行验收另列于交接记录。
