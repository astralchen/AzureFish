# 朋友圈图文与视频

本轮代码接入客户端与独立服务端，限现有隔离虚构账号环境；实际运行证据见[验证记录](validation.md)。本功能不表示生产部署、系统推送已经完成。

## 客户端组织

客户端按 Chat 的职责分层组织为 Controllers、Models、ViewModels、Views 和 Support，详见[模块说明](../../../AzureFish/Features/Moments/README.md)。动态流、发布和评论由独立 ViewModel 管理页面状态；Runtime 继续管理窗口业务数据、账号任务和加密资源。组件以类型化事件上报操作，ListKit 视图负责行身份和阅读锚点。此重构不改变网络契约、数据库结构或页面业务规则；本次验证与历史功能证据分别记录。

## 页面与行为

主界面为“聊天／通讯录／发现／我”，默认仍选聊天。发现页进入朋友圈；“我”和可互发消息的好友资料提供相册入口。朋友圈和个人相册的 collectionView 铺满当前页面，随窗口尺寸变化，不再限制整个列表的宽度；系统自动调整滚动内容的安全区域，图片区域继续使用下文的尺寸上限。导航、键盘和弹出菜单由系统托管。iOS 15～25 不仿制玻璃，26+ 继承系统外观。

动态支持纯文字、纯图片、图文及有序九图，正文最多 2,000 Character／64 KiB。相册和动态流复用页面，按服务端序号倒序、固定上界分页。用户可展开长文、查看原图、缩放和前后切图、点赞／取消、评论／回复、删除自己的动态或评论。封面采用可拖动缩放的 2:1 裁剪，上传无位置元数据的 JPEG；取消封面恢复默认图案。

列表接近底部 240 pt 时自动续页，减速及短列表未填满窗口时也检查加载条件；每个页面同时只发起一次续页，必须先取得第一页游标。底部使用无分隔线、至少 64 pt 高的居中页脚：空闲时留白，加载时显示系统转轮，失败时显示“加载失败，轻触重试”，服务端确认没有下一页后显示 36 pt 短线。VoiceOver 可主动加载下一页，并读出加载、失败及已显示全部动态的状态；重试文案提供四语言。续页错误只显示在底部，保留已有动态、阅读锚点和游标，不反复自动重试；点击页脚重试同一页，下拉刷新则重新校验并取第一页。续页不重复读取封面，离线不显示加载转轮或错误的结束标记。

照片从系统 PHPicker 导入，下采样到最长边 2,048 像素并重新编码 JPEG，不上传原位置元数据；首版把 Live Photo／动画照片作为静态照片导入。页面文案提供简中、繁中、英文、阿拉伯语，复用 AppLocalization 和 String Catalog。

图片区域按数量排布：单图保持横竖比例，最大 280×360 pt；2／3 张为一行，4 张为 2×2，5～9 张每行最多 3 张，末行保持原顺序。多图使用统一正方形缩略图、4 pt 间距，按可用正文宽度缩小，三列网格最大 320 pt；两列不拉伸填满正文。在 iPad 或宽窗口中也保持此上限，点开预览查看完整图片。

图片预览采用黑底全屏模态页面，复用自定义 `AttachmentPagingLayout` 与 ListKit；按当前窗口整页横向滚动，页间距固定 20 pt，首尾不增加空白页，单次手势最多切换一页。单击显隐系统关闭按钮与页码，双击在原始比例与 3 倍间切换，捏合支持 1～5 倍；放大时在图片内部拖动查看，移到左右边缘后再次向外横滑即可翻页，无需先缩回；捏合期间暂停分页。原始比例下可下拉关闭，取消拖动恢复原位；关闭保留动态列表阅读位置。辅助功能提供翻页及关闭操作，“减少动态效果”关闭缩放转场和程序翻页动画。

预览仅为当前及相邻页发起加载，已发起的请求跨页复用，来回翻页不重复启动相同请求。优先同步显示账号内缓存的原图，其次显示列表缩略图并在后台读取原图；读取失败保留缩略图及重试入口。账号预览缓存按最近使用顺序最多保留 9 张、总解码成本最多 96 MiB 的原图，关闭后重新打开仍可复用；超限淘汰或内存警告后允许重新读取加密媒体。关闭预览取消未完成任务，动态失权、删除或账号停止时同时清除缓存与展示，请求代次阻止迟到结果恢复图片。旋转、窗口变化和缩略图升级为原图时保留当前图片的缩放比例与查看中心。预览图片等比适配窗口，使用原始方向，不随 RTL 镜像。

列表图片与封面按账号、资源版本及引用目标绑定，UIKit 菜单／高亮状态或相同数据的重复配置保留当前图片和加载任务。列表只重配有可见变化的行；预览返回或后台校验返回相同数据时保持原内容。运行时按最近使用顺序缓存最多 36 张、总解码成本最多 32 MiB 的列表图片，新 Cell 同步命中缓存直接显示图片。仅有加密磁盘缓存时仍异步解密，加载期间保留图片区域而不插入默认图片图标；未设置封面时才显示默认封面。缓存不落明文文件，退出／删除／失权同步清除缓存及复用视图中的图片。

## 视频发布与播放

动态允许一段视频及可选文字，与图片互斥。发布编辑器分别提供相册照片、相册视频和现场拍摄入口；系统拍摄最多 60 秒，需要相机及麦克风权限。视频选取后先将源文件流式加密到账号草稿，再进入系统裁剪器，最长选段 60 秒。确认后导出最高 1080p 的 MP4、清空可选元数据，并生成 JPEG 封面。原始素材、导出视频、封面和上传身份均有草稿资源引用；重新裁剪使用新导出身份。系统裁剪器不公开选段起点，`trimStart` 保持 nil；已选内容由加密导出文件精确保存，`trimDuration` 记录实际时长，不猜测时间偏移。再次裁剪从保留的原始素材打开。

视频封面复用单图的最大 280×360 pt 和缓存绑定，叠加播放图标及时长，不在列表自动播放。点击黑底全屏展示系统 AVPlayer 控件；原件分块进入加密缓存并完整校验后申请受保护的临时文件租约，首帧就绪前保留封面。加载／失败时显示页面关闭按钮，播放就绪后切换为 AVKit 自带关闭控件，避免重复按钮遮挡系统静音控件。关闭、失权或退出停止播放并释放租约，后台暂停；关闭后保留列表阅读位置。完整加密缓存可以离线播放，在线重新申请权限，重复查看不重复下载已有分块。首版不支持画中画、外部播放、配乐、贴纸或多视频混排。

## 权限与刷新

动态、相册及封面仅本人或当前双向好友可见，包括成为好友之前的历史。删除联系人或拉黑使双方停止互看。作者可见全部互动；其他人只能看到本人和自己的当前双向好友互动。回复者及被回复者都必须可见，服务端不返回被过滤对象的隐藏数量。

首次进入、回到前台、下拉和同账号其他窗口写入后刷新。每次刷新对已载入动态批量校验，再获取第一页；权限失效立即清理展示。好友投影变化先过滤本地内容，再联网确认；离线显示明确提示及仍可用的缓存。已离线下载的字节不能被远程即时收回。

当前没有朋友圈 WebSocket 事件、互动通知页、红点或 APNs。只有手动重试才继续失败的发布和互动，不自动发布已保存草稿。

## 草稿及恢复

`AzureFishMoments` 提供独立业务存储和媒体工作，复用账号的 SQLCipher 主库与 EncryptedMediaStore。草稿以独立 UUID 隔离窗口；同账号窗口不能同时打开同一草稿。文字、图片顺序、上传创建／完成操作 ID、发布原始字节均加密保存。

上传部分失败时，重试查询服务端完成分块并补传缺失部分。提交发布后内容冻结；响应丢失先查询原动态 ID，已接受则清理草稿，未接受才复用原字节和原 operation_id。封面提交同样保留目标资产与操作身份；版本冲突刷新当前封面版本并保留本地照片。关闭编辑器可保存或丢弃；结果尚未确认时只允许保存，避免另建身份重复提交。

聊天账号存储所有者统一登记迁移及资源引用；退出和清除数据先取消、等待朋友圈任务，再关闭业务入口与账号存储。普通退出保留密文和密钥；显式清理沿用现有账号流程。启动补偿中断的图片导入，文件清理成功前保留恢复记录。
