## 2. 页面与完整流程

XCTest/XCUIAutomation 覆盖欢迎 → 注册 → 我 → 编辑资料 → 退出 → 再登录；另测绑定 Apple、Apple-only 设置密码和删除账号。身份验证依赖分为确定性 mock UI 与真实系统授权，报告分开。

- 分别验证 iOS／iPadOS 15～25 的非液态玻璃外观、iOS／iPadOS 26+ 的系统 Liquid Glass，以及 iOS 27.1+ Duo 适配；旧系统聊天仍兼容占位，认证最低版本保持 iOS 15。
- Liquid Glass 专用 API 不进入 iOS 26 以下路径，Duo 专用 API 另按 iOS 27.1 检查；各外观分支的页面功能、输入与导航状态一致。
- 冷启动首帧不显示旧用户；刷新过程不闪回欢迎；首次进入表单焦点、键盘安全区正确。
- 提交、错误、重试时组件不意外移动；长昵称、长错误和辅助功能字体可完整阅读。
- VoiceOver、深浅色、iPad 窗口变化、iOS 27.1 Duo 内外屏及简中／繁中／英文／阿拉伯语 RTL 分别验证。
- 三类系统外观均覆盖大字体及“降低透明度”“增强对比度”关闭、分别开启和同时开启；不以默认设置下的截图代替辅助功能验收。
- 欢迎页外观菜单和“我 → 应用设置 → 外观”提供跟随系统／浅色／深色，勾选当前偏好；缺失或无效值默认跟随系统。
- 浅色／深色手动选择在重启、退出及切账号后保持，首个可见帧不闪现错误主题；恢复跟随系统后立即响应系统外观变化。
- 现有、新建及后台恢复的应用窗口采用同一偏好策略；手动选择不被系统切换覆盖，跟随系统时不将某窗口解析出的颜色写成固定偏好。
- 登录输入、资料编辑、头像上传及弹层展示过程中切换主题，保持焦点、输入、导航、滚动与 operation_id，请求次数不增加。
- 四语言外观名称、选中状态和 VoiceOver 标签正确；语言与主题连续切换互不覆盖偏好，用户照片／媒体不反色。
- 头像取消、确认、上传失败、成功后取消文字编辑符合“头像独立生效”约定。
- 同一 Wi-Fi 真机完成 HTTPS、局域网权限和证书验证；不能用模拟器通过替代。
- 保留 -chat-ui-test-root 原有聊天测试路径；Release 没有绕过鉴权入口。
