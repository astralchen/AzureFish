# 2026-09-26 客户端验收记录

本轮限定 Debug 模拟器与本机虚构账号服务。注册、重启恢复、资料保存和退出核心流程已通过，其余结果按实际执行记录；不将编译、预览或历史记录当作运行通过。

## 环境与运行方式

- Xcode 26.5（17F42），iOS Simulator SDK 26.5，Intel x86_64 主机。
- 复用 iPhone 17 Pro／iOS 26.5（23F77），UUID `505FE0AF-BD0B-4257-A44A-A3BA1364CF5C`。验收固定使用上述设备，禁用并行和克隆选项，未清空设备数据。
- 所有测试使用 `-parallel-testing-enabled NO -maximum-concurrent-test-simulator-destinations 1`。仅在替换构建、切换独立测试场景或验证进程恢复时重启应用。
- 本机服务绑定 `127.0.0.1:8080`，环境为 `local-development`，数据与密钥置于 `/tmp/azurefish-client-fictional`，只创建虚构账号。
- Keychain 验收使用 `CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=-` 的模拟器临时签名；早期未签名测试包无法读取 Keychain，未计为通过。
